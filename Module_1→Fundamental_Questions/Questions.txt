Q.1)→ Your team is setting up a new analytics environment for a sales project in Databricks Unity Catalog.
      Write the SQL statements to:
        • Create a catalog named sql_practice if it does not already exist.
        • Switch to the newly created catalog.
        • Display all available catalogs.
        • Create a schema named sales inside the sql_practice catalog if it does not already exist.
        • Switch to the sales schema.
        • Display all schemas available in the current catalog.
Q.2)→ Your team is designing a Delta Lake table to store sales data. The table should support efficient writes, Change Data Feed (CDF), column mapping, 
      and optimized file management for future ETL workloads.
      Write a SQL statement to create a Delta table named order_sales with the following requirements:
      Store the columns:
        • order_id as an integer
        • customer_name as a string
        • amount as a double
        • date_arrival as a date
        • Enable column mapping using name mode.
        • Enable Change Data Feed (CDF).
        • Enable Optimize Write.
        • Enable Auto Compaction.
        • Retain deleted data files for 7 days.
        • Retain Delta transaction logs for 30 days.
        • Ensure the table is created only if it does not already exist.
Q.3)→ Before reloading fresh sales data into the order_sales table, you need to remove all existing records while preserving the table structure, schema, 
      and properties.
      Write a SQL statement to accomplish this.
Q.4)→ The order_sales table is no longer required because it has been replaced by a new version.
      Write a SQL statement to permanently remove the table and all of its associated metadata from the database.
Q.5)→ The business has introduced two new attributes for the sales dataset:
        • order_name
        • cust_id
      These columns must be added to the existing order_sales table. Additionally, the reporting team requires order_name to appear immediately after order_id 
	and cust_id immediately after order_name.
      Write a SQL statement to modify the table accordingly.
