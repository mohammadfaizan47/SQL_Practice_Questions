Q.1)→ The finance team wants to analyze how sales have accumulated over time instead of viewing only individual order amounts.
      Write a SQL query to display all order details along with:
        • the running (cumulative) total of order_amount, and
        • the running (cumulative) average of order_amount,
      based on the chronological order of order_date.
Q.2)→ The finance team wants to track cumulative sales over time. Instead of relying on the default behavior of window functions, they want the 
      calculation to explicitly include all rows from the first order up to the current order.
      Write a SQL query to display all order details along with the running total of order_amount, explicitly defining the window frame.
Q.3)→ The finance team wants every order in the sales report to display the overall sales amount of the company, while still showing each individual order.
      Write a SQL query to display all order details along with the total sales across all orders. The total sales should appear on every row of the result.
Q.4)→ The finance team wants to compare orders based on their value and understand how different ranking methods handle duplicate order amounts.
      Write a SQL query to display:
        • order_amount
        • a unique sequential number for each order,
        • the rank of each order,
        • and the dense rank of each order,
      based on order_amount in ascending order.
Q.5)→ The business wants to compare the value of orders within each product category rather than across the entire dataset.
      Write a SQL query to display:
        • category
        • order_amount
        • a unique sequential number for each order within its category,
        • the rank of each order within its category,
        • and the dense rank of each order within its category,
      based on order_amount in ascending order.
