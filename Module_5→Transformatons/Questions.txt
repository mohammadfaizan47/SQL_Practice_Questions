Q.1)→ The finance team wants to analyze the pricing of each order after applying different pricing stages. For every order in the orders table:
      • Add a fixed tax of 1000 to the original order_amount and name it taxed_price.
      • After tax, apply a promotional discount of 500 and name the result offed_price.
      • Calculate 10% of the discounted price and display it as discounted_amount.
      • Calculate the final payable amount after applying a 10% discount on the discounted price and name it discounted_price.
      • Round the final payable amount to one decimal place and display it as rounded_price.
Q.2)→ While generating an audit report, the operations team wants to compare each order's recorded date with the system's current date and time.
      Write a SQL query to display:
        • the order_date,
        • the current system date,
        • the current system time,
        • and the current system timestamp
Q.3)→ The reporting team is building a calendar-based sales dashboard and needs additional date-related information for every order.
      Write a SQL query to display the following for each order:
        • The original order_date.
        • The year, month, and day extracted from the order date.
        • The numeric day of the week and the corresponding day name.
        • The date 2 days after the order date.
        • The date 2 days before the order date.
        • The total number of days between the order date and the current system date.
        • Convert the string '2026-01-01' into a TIMESTAMP and display it as a separate column.
Q.4)→ The business team wants order dates to be displayed in a user-friendly format for a customer-facing report instead of the default database format.
      Write a SQL query to display:
        • the original order_date, and
        • the same date formatted as:
           Day, Year-Month-Day
Q.5)→ The customer IDs are currently stored as numeric values. A downstream application requires them to be sent as text for data integration.
      Write a SQL query to display:
        • the original customer_id, and
        • the same customer_id converted to a string data type with a maximum length of 100 characters.
Q.6)→ A reporting dashboard requires a single descriptive field for each customer instead of displaying multiple columns.
      Write a SQL query to create:
        • a column combining customer_name and city, and
        • another column combining customer_name, city, and age, with each value separated by a space.
Q.7)→ The customer support team wants to analyze the length of city names for data quality and reporting purposes.
      Write a SQL query to display all customer details along with the number of characters present in each customer's city name.
Q.8)→ As part of a customer data standardization process, the business team requires multiple transformations on customer information.
      Write a SQL query to display:
        • the original city,
        • the city name in lowercase,
        • the city name in uppercase,
        • the first four characters of the membership_type,
        • and a modified version of the city where every occurrence of 'Delhi' is replaced with 'Jaipur'.
