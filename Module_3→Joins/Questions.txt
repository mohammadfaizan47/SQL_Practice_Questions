      Write a SQL query to display all customer details along with their order information. Customers who have not placed any orders should still

      record should still appear in the result.
Q.3)→ The business wants a single report containing all customer names and supplier names in one list.
      Write a SQL query to combine the names from both tables into a single result set while removing duplicate values.
